# Godot fight (app/game3d): asset licences

Every file under `app/game3d/art/` is listed here with its source and licence. Nothing is
from Mixamo, Sketchfab or a ripped game, and nothing came from an AI image service.

The project's own CC0 sets below were made for the earlier Unity street build
(costquest-unity, branch `street-look`, commit 47560e4) and are copied here as plain files.
No Unity software was installed or run for this; the files were read from an existing
checkout on the farm (`~/cq-work/game-godot/ext/unity-ref`, cq 061's read-only copy).

## HUD (art/hud/)
- stick_base, stick_knob, btn_base, btn_ring, btn_ring_ult, icon_attack, icon_dodge,
  icon_guard, icon_skill_shockwave, icon_skill_crescent, icon_skill_arcane, icon_ultimate,
  coin_heal, coin_heal_off, coin_shield, coin_shield_off, coin_power, icon_person,
  minimap_frame, marker_hero, marker_ally, marker_boss, pill_timer, pill_squad (.png).
- Source: the project's own HUD kit, procedurally painted by `hud_src/icons.py` and
  `hud_src/kit.py` (numpy + PIL). These are the icons on the reference sheet
  `hud_icon_sheet.png`. Licence: **CC0 1.0** (own work; no third-party pixels).
- icon_dodge_off, icon_ultimate_off, icon_skill_crescent_off, icon_skill_shockwave_off,
  icon_skill_arcane_off (.png): the cooldown copies of those icons, desaturated with
  ImageMagick (`-modulate 92,12`) (cq 011). **CC0 1.0**.

## Fonts (art/fonts/)
- LilitaOne-Regular.ttf: Lilita One by Juan Montoreano, **SIL Open Font License 1.1**,
  https://fonts.google.com/specimen/Lilita+One (the same file the Unity build shipped).

## Effects (art/fx/)
- spark_04, star_06, flare_01, slash_02, circle_05, scorch_01, magic_02 (.png, downscaled
  to 256 px): Kenney "Particle Pack" 1.1, https://kenney.nl/assets/particle-pack,
  **CC0 1.0** (`art/fx/License_Kenney_ParticlePack.txt`).
- vfx_blade_trail, vfx_crescent, vfx_swirl, vfx_glow, vfx_ring_fire, vfx_coin, vfx_beam (.png):
  the project's own VFX set, generated by `staging/vfx/make_textures.py` (numpy + PIL),
  **CC0 1.0**. vfx_pillar.png is vfx_beam.png faded towards its top with ImageMagick (cq 011),
  **CC0 1.0**. The coin's "C" is drawn with Lilita One (OFL 1.1 allows rendered glyphs in artwork).

## Street (art/street/)
- street_pavers, medallion, circuit_run, light_pool (.png): the project's own ground and
  light passes (`assets/ground/src/*.py`, `assets/light/make_textures.py`; numpy + PIL),
  **CC0 1.0**.
- neon_atlas.png (six neon shop signs stacked: RAMEN, ARCADE, CAFE, 24H, GYM, NOODLE),
  shop_glow.png, lamp_glow.png: drawn with ImageMagick 7 for cq 011 (rounded-rectangle
  strokes, blurs and radial gradients; the sign words are set in Lilita One, OFL 1.1, which
  allows rendered glyphs in artwork). Own work, **CC0 1.0**.
